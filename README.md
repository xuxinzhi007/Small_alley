# 小巷物语

游戏名是「小巷物语」。从家走出去，菜市场、单位、公园都在同一片路上。种子会自己长，硬币花出去还能再挣回来。

点右上角「地图」，会弹出这一带的大地图：家、楼道、小区、便利店、菜市场、广场、公园、书店、咖啡馆、超市、公交站、地铁站、单位。点一个地方，会沿着路走过去，路程越远花的时间越长。不会从咖啡馆直接送回家。想回家，就在地图上选「家」，或者顺着路一截一截走回去。

到了地方之后，按住卡片左右滑。滑完先停在刚才发生的事上。林阿姨在楼道，店主在咖啡馆。一天从早上七点走到晚上十点。

顶上是钟点、硬币、种子、文化、邻里和背包，都排在微信胶囊下面。每天还会提示一处值得去的地方。

用微信开发者工具打开本目录，编译类型选小游戏，竖屏预览。开发者工具里的项目名称是「小巷物语」。

牌、偶然事件、背包、标记和每天的小记都写在本机的一张表里（`js/sql.js`）。以后如果接后端，换掉这一层即可。

新的牌和偶然事件加在 `js/content.js`。雯宝的形象来自 Kenney.nl，CC0。
